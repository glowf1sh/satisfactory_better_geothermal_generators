# Better Geothermal Generators v2 (fixed & based on Mastrmyrtr9's Mod)

Two powerful Geothermal Generators for Satisfactory – **x10** and **x100** – delivering a rock-solid **2,000 MW** and **20,000 MW**. No more fluctuating output, no more node purity lottery: just plug in and power your factory.

- Unlocked in Tier 8 (x10) and Tier 9 (x100)
- Constant output, independent of node purity
- Updated for **Satisfactory 1.2** / SML 3.12

## Installation

Install via the [Satisfactory Mod Manager](https://smm.ficsit.app/) – search for **Better Geothermal Generators v2**.

## Upgrading from the original "Better Geothermal Generators"

Existing saves keep working: generators built with the original mod are redirected automatically. Remove the old mod and install this one.
