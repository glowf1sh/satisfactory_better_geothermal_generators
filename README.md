# Better Geothermal Generators v2 (fixed and based on Mastrymyrtr9s Mod)
Adds a Geothermal Generator x10 and x100 which produce a (constant) 2,000mw and 20,000mw respectively. Node purity does not effect the amount produced. Unlocked in tier 8 and 9. A fork of Mastrmyrtr9 "Better Geothermal Generator" Mod that is broken and not maintained anymore. Runs with Satisfactory in Unreal Engine 5.6 (Satisfactory 1.2 and above).

Based on https://github.com/Mastrmyrtr9/BetterGeothermal
